## As built

A peek through the corner into a snowy night sky: stars, a moon placed on a wall, snow, and Santa's sleigh crossing the moon. The moon position and size, Santa's height, and the snow amount and speed are set live from the web UI (Sky tab). Snow changes affect only new flakes.

## Viewing notes
